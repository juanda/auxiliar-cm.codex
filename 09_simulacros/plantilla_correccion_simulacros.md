# Plantilla de correccion de simulacros

Plantilla comun para corregir `simulacro_01.md`, `simulacro_02.md` y `simulacro_03.md`.

## Regla de puntuacion

Formula oficial de practica:

```text
puntuacion = aciertos - errores / 3
```

Criterios:

- Acierto: `+1`.
- Error: `-1/3`.
- Blanco: `0`.
- Las preguntas de reserva solo se corrigen si sustituyen a una pregunta ordinaria anulada del mismo ejercicio.
- Si no hay anulaciones, el primer ejercicio se calcula sobre 60 preguntas ordinarias y el segundo ejercicio sobre 30 preguntas ordinarias.

## Metodo de correccion

1. Corrige cada respuesta con la plantilla incluida al final del simulacro.
2. Marca cada pregunta ordinaria como `Acierto`, `Error` o `Blanco`.
3. Si una pregunta ordinaria se anula, no la cuentes y sustituye por la primera reserva disponible del mismo ejercicio.
4. Calcula por separado primer ejercicio y segundo ejercicio.
5. Registra los resultados en la tabla de seguimiento para comparar evolucion.

## Formulas utiles

```text
blancos = preguntas_evaluadas - aciertos - errores
puntuacion = aciertos - errores / 3
porcentaje = puntuacion / preguntas_evaluadas * 100
```

Ejemplo:

```text
preguntas_evaluadas = 60
aciertos = 42
errores = 12
blancos = 6
puntuacion = 42 - 12 / 3 = 38
porcentaje = 38 / 60 * 100 = 63,33%
```

## Diagnostico rapido

| Resultado | Lectura practica | Accion recomendada |
| --- | --- | --- |
| Menos del 50% | Base insuficiente o demasiados errores penalizados. | Rehacer el bloque con temario y corregir errores uno a uno. |
| 50% - 65% | Nivel de aprobacion incierto. | Priorizar temas con errores repetidos y reducir respuestas dudosas. |
| 65% - 80% | Nivel competitivo en practica. | Entrenar velocidad y reservas; revisar fallos finos. |
| Mas del 80% | Buen dominio del simulacro. | Subir dificultad y hacer repasos espaciados. |
