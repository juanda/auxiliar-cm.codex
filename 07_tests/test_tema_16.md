# Test Tema 16. Windows 10

Preguntas nuevas de entrenamiento predictivo para Windows 10. Se combinan recurrencias históricas del Explorador con puntos probables de convocatoria: búsqueda, Este equipo, Acceso rápido, accesorios y herramientas del sistema.

## Preguntas

1. ¿Qué combinación de teclas abre el Explorador de archivos?
   A. `Alt + Tab`
   B. `Windows + E`
   C. `Ctrl + E`
   D. `Alt + F4`

2. ¿Dónde se muestra la ruta completa de una carpeta abierta?
   A. Barra de direcciones
   B. Panel de vista previa
   C. Papelera
   D. Administrador de tareas

3. ¿Qué muestra principalmente `Este equipo`?
   A. Sólo archivos recientes
   B. Unidades, dispositivos y carpetas principales
   C. Procesos activos
   D. Servicios de Windows

4. ¿Qué muestra `Acceso rápido`?
   A. Carpetas frecuentes o ancladas y archivos recientes
   B. Sólo unidades de disco
   C. Sólo procesos en ejecución
   D. Sólo impresoras

5. Desanclar una carpeta de Acceso rápido:
   A. Elimina la carpeta del disco
   B. Quita el acceso sin borrar la carpeta real
   C. Formatea la unidad
   D. Cambia su extensión

6. ¿Qué permite el panel de vista previa?
   A. Ver contenido de ciertos archivos sin abrirlos
   B. Cambiar contraseñas
   C. Ejecutar servicios
   D. Administrar particiones

7. La extensión de un archivo es:
   A. La parte final del nombre tras un punto
   B. El usuario propietario
   C. El número de carpetas que contiene
   D. El espacio libre de la unidad

8. Si un archivo no tiene aplicación asociada, Windows muestra normalmente:
   A. `¿Cómo quieres abrir este archivo?`
   B. El Programador de tareas
   C. El Visor de eventos
   D. La Calculadora

9. Compartir una carpeta significa:
   A. Hacer su contenido accesible a otros usuarios de la red
   B. Reducir su tamaño
   C. Cambiar su extensión
   D. Borrarla temporalmente

10. ¿Por qué conviene quitar de forma segura una memoria USB?
    A. Para evitar pérdida de datos
    B. Para crear una carpeta personal
    C. Para iniciar Paint
    D. Para cambiar la fecha del sistema

11. Al agrupar archivos, el número entre paréntesis junto a cada grupo indica:
    A. Número de archivos del grupo
    B. Número de aplicaciones instaladas
    C. Número de permisos
    D. Número de usuarios

12. ¿Qué herramienta muestra procesos activos en tiempo real?
    A. Administrador de tareas
    B. Bloc de notas
    C. WordPad
    D. Recortes

13. ¿Qué comando abre el Administrador de discos?
    A. `devmgmt.msc`
    B. `services.msc`
    C. `diskmgmt.msc`
    D. `taskschd.msc`

14. ¿Qué comando abre el Administrador de dispositivos?
    A. `diskmgmt.msc`
    B. `devmgmt.msc`
    C. `services.msc`
    D. `notepad.exe`

15. ¿Qué comando abre Servicios?
    A. `services.msc`
    B. `mspaint.exe`
    C. `taskschd.msc`
    D. `calc.exe`

16. ¿Qué comando abre el Programador de tareas?
    A. `taskschd.msc`
    B. `services.msc`
    C. `diskmgmt.msc`
    D. `devmgmt.msc`

17. ¿Qué patrón buscaría archivos PDF?
    A. `pdf?`
    B. `*.pdf`
    C. `.pdf*exe`
    D. `pdf:unidad`

18. En una búsqueda, el comodín `*` representa:
    A. Un único carácter
    B. Sólo unidades USB
    C. Sólo carpetas compartidas
    D. Cualquier cadena de caracteres

19. En una búsqueda, el comodín `?` representa:
    A. Una carpeta
    B. Un único carácter
    C. Cualquier cadena completa
    D. Una unidad

20. ¿Qué vista muestra columnas como tipo, fecha de modificación y tamaño?
    A. Iconos grandes
    B. Detalles
    C. Modo lectura
    D. Diseño web

21. ¿Qué diferencia hay entre ordenar y agrupar?
    A. Agrupar elimina archivos
    B. Ordenar cambia el orden; agrupar separa en categorías
    C. Ordenar sólo funciona en USB
    D. Son siempre lo mismo

22. ¿Qué accesorio edita texto sin formato?
    A. Paint
    B. Calculadora
    C. Bloc de notas
    D. Visor de eventos

23. ¿Qué accesorio permite hacer capturas de pantalla?
    A. Administrador de discos
    B. Calculadora
    C. Servicios
    D. Recortes / Recorte y anotación

24. ¿Qué accesorio se usa para cálculos?
    A. Administrador de tareas
    B. Calculadora
    C. Acceso rápido
    D. Visor de eventos

25. ¿Qué herramienta consulta registros del sistema?
    A. Paint
    B. WordPad
    C. Visor de eventos
    D. Calculadora

26. ¿Qué herramienta puede ayudar a liberar espacio?
    A. Mapa de caracteres
    B. Paint
    C. Barra de direcciones
    D. Sensor de almacenamiento

27. ¿Qué permite `Propiedades` de un archivo?
    A. Ver procesos activos
    B. Ver información como tipo, ubicación, tamaño y fechas
    C. Programar tareas
    D. Abrir servicios

28. ¿Qué significa mover un archivo?
    A. Crear una copia sin tocar el original
    B. Cambiar la extensión únicamente
    C. Cambiarlo de ubicación
    D. Compartirlo por red siempre

29. ¿Qué significa copiar un archivo?
    A. Eliminar siempre el original
    B. Cambiar permisos de red
    C. Formatear la unidad
    D. Crear un duplicado

30. ¿Qué función tiene la Papelera de reciclaje?
    A. Mostrar unidades de disco
    B. Administrar procesos
    C. Guardar temporalmente muchos elementos eliminados para posible restauración
    D. Cambiar asociaciones de archivo

31. ¿Qué indica normalmente la carpeta personal?
    A. Una carpeta compartida obligatoria
    B. La carpeta propia de cada usuario del equipo
    C. La Papelera
    D. El Administrador de tareas

32. ¿Qué se puede consultar desde las propiedades de una unidad?
    A. Sólo el nombre del usuario
    B. Sólo procesos activos
    C. Capacidad y espacio libre
    D. Sólo archivos recientes

33. ¿Qué hace la indexación?
    A. Ayuda a acelerar búsquedas en ubicaciones incluidas
    B. Borra duplicados automáticamente
    C. Cambia extensiones
    D. Formatea discos

34. ¿Qué herramienta permite administrar hardware y controladores?
    A. Bloc de notas
    B. Acceso rápido
    C. Administrador de dispositivos
    D. Calculadora

35. ¿Qué opción describe mejor el panel de detalles?
    A. Abre siempre el archivo
    B. Sustituye al Administrador de discos
    C. Elimina unidades
    D. Muestra información del elemento seleccionado
