# Test Tema 17. Word

Preguntas nuevas de entrenamiento predictivo para Word de Microsoft 365 escritorio. Se priorizan contenidos no agotados por los exámenes históricos: estilos, secciones, impresión, exportación, revisión, vistas y personalización.

Tiempo recomendado: 41 minutos (ritmo del segundo ejercicio real: ~70 segundos por pregunta). Criterio de corrección: `aciertos - errores / 3`.

## Preguntas

1. ¿Qué comando permite guardar un documento abierto con otro nombre?
   A. Guardar
   B. Guardar como
   C. Cerrar
   D. Buscar

2. El interlineado es:
   A. El color del texto
   B. El espacio vertical entre las líneas de un párrafo
   C. El encabezado del documento
   D. El margen superior

3. ¿Qué permite localizar palabras dentro de un documento?
   A. Buscar
   B. Disposición
   C. Imprimir
   D. Formato

4. La sangría izquierda desplaza:
   A. La página completa
   B. El párrafo respecto al margen izquierdo
   C. El encabezado
   D. El pie de página

5. Las secciones permiten:
   A. Configuración propia en partes del documento
   B. Cambiar sólo el color del texto
   C. Eliminar metadatos
   D. Abrir Excel

6. Para insertar un documento dentro de otro se usa:
   A. Objeto
   B. Ortografía
   C. Zoom
   D. Diseño web

7. Las propiedades del documento son:
   A. Metadatos
   B. Márgenes
   C. Párrafos
   D. Interlineados

8. ¿Qué vista muestra el aspecto que tendrá el documento impreso?
   A. Esquema
   B. Modo lectura
   C. Diseño de impresión
   D. Borrador

9. Una lista numerada comienza con:
   A. Un número, letra o esquema
   B. Una imagen obligatoria
   C. Una tabla
   D. Una propiedad

10. En comodines de Word, `!` dentro de corchetes sirve para:
    A. Excluir caracteres
    B. Guardar el archivo
    C. Insertar un objeto
    D. Cambiar el margen

11. En Word de Microsoft 365 escritorio, ¿qué opción permite sustituir automáticamente una palabra por otra en un documento?
    A. Reemplazar
    B. Diseño de impresión
    C. Inspeccionar documento
    D. Dividir ventana

12. ¿Qué diferencia principal hay entre un salto de página y un salto de sección?
    A. El salto de página permite cambiar márgenes y el de sección no
    B. El salto de página fuerza una página nueva; el salto de sección permite configuración propia
    C. Ambos son exactamente iguales
    D. El salto de sección sólo sirve para numerar listas

13. ¿Qué elemento de Word permite aplicar de forma uniforme un conjunto de formatos a títulos o párrafos?
    A. Comentario
    B. Marcador de impresión
    C. Estilo
    D. Zoom

14. ¿Qué opción pertenece al formato de fuente?
    A. Sangría izquierda
    B. Interlineado
    C. Espaciado posterior
    D. Tamaño de letra

15. ¿Qué opción pertenece al formato de párrafo?
    A. Color de fuente
    B. Alineación
    C. Negrita
    D. Tipo de letra

16. Los encabezados y pies de página son:
    A. Propiedades avanzadas del archivo
    B. Tipos de comentario
    C. Zonas repetibles en la parte superior e inferior de las páginas
    D. Vistas del documento

17. Si se quiere que una parte del documento tenga orientación horizontal y otra vertical, conviene usar:
    A. Viñetas
    B. Zoom
    C. Reemplazar
    D. Saltos de sección

18. ¿Dónde se configuran habitualmente impresora, copias e intervalo de páginas?
    A. Insertar -> Texto
    B. Archivo -> Imprimir
    C. Revisar -> Comentarios
    D. Vista -> Regla

19. Exportar un documento a PDF sirve principalmente para:
    A. Activar una lista numerada
    B. Cambiar el interlineado
    C. Generar una versión de salida para distribuir o imprimir
    D. Crear un comentario

20. El zoom en Word:
    A. Cambia el tamaño real de la fuente
    B. Cambia la visualización en pantalla
    C. Cambia el margen izquierdo
    D. Convierte el archivo en PDF

21. ¿Qué vista resulta especialmente útil para ver la jerarquía de títulos del documento?
    A. Esquema
    B. Borrador
    C. Diseño web
    D. Portapapeles

22. El panel de navegación funciona mejor cuando el documento utiliza:
    A. Sólo texto sin formato
    B. Imágenes sin texto
    C. Contraseñas de apertura
    D. Estilos de título

23. ¿Qué formato de archivo corresponde normalmente a un documento moderno de Word?
    A. `.xlsx`
    B. `.docx`
    C. `.pptx`
    D. `.accdb`

24. ¿Qué formato se asocia a una plantilla de Word?

    B. `.xlsx`
    C. `.dotx`
    D. `.csv`

25. ¿Qué opción permite tener comandos frecuentes siempre visibles?
    A. Encabezado
    B. Salto de columna
    C. Pie de página
    D. Barra de herramientas de acceso rápido

26. La cinta de opciones de Word:
    A. Guarda automáticamente una copia en PDF
    B. Agrupa comandos por pestañas y grupos
    C. Es una zona exclusiva de impresión
    D. Es el contenido del encabezado

27. ¿Qué función permite revisar modificaciones realizadas en un documento?
    A. Guardar como
    B. Diseño web
    C. Control de cambios
    D. Tamaño de papel

28. ¿Qué opción permite añadir una observación al margen sin cambiar directamente el texto principal?
    A. Sangría francesa
    B. Lista numerada
    C. Exportar
    D. Comentario

29. ¿Cuál es la diferencia más correcta entre `Guardar como` y `Exportar`?
    A. `Guardar como` puede cambiar nombre, ubicación o formato; `Exportar` genera una versión de salida como PDF
    B. `Exportar` siempre borra el documento original
    C. `Guardar como` sólo imprime
    D. No existe diferencia posible

30. ¿Qué opción se usa para crear una tabla de contenido automática?
    A. Sólo cambiar el zoom
    B. Guardar como PDF
    C. Estilos de título y referencias de tabla de contenido
    D. Insertar un comentario

31. ¿Qué elemento permite mostrar u ocultar la regla de Word?
    A. Guardar como
    B. Opciones de vista
    C. Propiedades avanzadas
    D. Ortografía

32. Si un documento contiene metadatos como autor, título y asunto, esos datos son:
    A. Márgenes
    B. Viñetas
    C. Sangrías
    D. Propiedades del documento

33. ¿Qué acción corresponde a `Archivo -> Abrir`?
    A. Insertar una lista con viñetas
    B. Cambiar el interlineado
    C. Acceder a documentos existentes y recientes
    D. Activar el control de cambios

34. ¿Qué opción controla el espacio antes o después de un párrafo?
    A. Espaciado de párrafo
    B. Tamaño de fuente
    C. Comentario
    D. Exportar

35. ¿Qué afirmación sobre las secciones es correcta?
    A. Una sección siempre equivale a una sola página
    B. Una sección puede tener configuración de página propia
    C. Una sección sólo sirve para insertar hipervínculos
    D. Word no permite secciones
