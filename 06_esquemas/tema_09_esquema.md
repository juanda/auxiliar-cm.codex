# Tema 9. Contratos del Sector Público - Esquema de repaso

## Núcleo oficial

Elementos comunes, tipos contractuales, procedimientos de contratación y formas de adjudicación.

## Norma

| Norma | Dato |
| --- | --- |
| Ley 9/2017, de 8 de noviembre | Contratos del Sector Público |
| Entrada en vigor | 09/03/2018 |
| Última actualización BOE verificada | 09/04/2026 |

## Principios

| Principio / regla | Clave |
| --- | --- |
| Libertad de acceso | Licitaciones abiertas a operadores aptos |
| Publicidad y transparencia | Procedimientos visibles y controlables |
| Igualdad y no discriminación | Trato igual a licitadores |
| Eficiencia | Mejor uso de fondos públicos |
| Criterios sociales y medioambientales | Transversales y vinculados al objeto |

## Elementos comunes

| Elemento | Idea |
| --- | --- |
| Partes | Órgano de contratación y contratista |
| Contratista | Capacidad, solvencia, no prohibición |
| Objeto | Determinado; no fraccionamiento indebido |
| Valor estimado | Sin IVA; determina régimen |
| Precio | Retribución del contratista |
| Pliegos administrativos | Derechos, obligaciones, criterios |
| Pliegos técnicos | Características técnicas |
| Libertad de pactos | Interés público, ordenamiento y buena administración |
| Forma | No verbal salvo emergencia |

## Tipos

| Tipo | Clave |
| --- | --- |
| Obras | Ejecución de obra |
| Concesión de obras | Obra + explotación + riesgo operacional |
| Concesión de servicios | Servicio + gestión/explotación + riesgo operacional |
| Suministro | Compra o arrendamiento de bienes muebles |
| Servicios | Prestación de hacer distinta de obra/suministro |
| Mixto | Prestaciones de varios tipos |

## Contrato menor

| Tipo | Valor estimado inferior a |
| --- | ---: |
| Obras | 40.000 euros |
| Suministros | 15.000 euros |
| Servicios | 15.000 euros |

Importes sin IVA.

| Procedimiento | Clave |
| --- | --- |
| Abierto | Todo interesado presenta oferta |
| Abierto simplificado | Abierto más ágil |

| Negociado | Se negocian condiciones |
| Diálogo competitivo | Soluciones para contratos complejos |

## Trampas

| Trampa | Correcto |
| --- | --- |
| Criterios profesionales | Sociales y medioambientales |
| Sin relación con objeto | Deben vincularse al objeto |
| Obras menor 15.000 | Obras: 40.000 |
| Suministros menor 40.000 | Suministros: 15.000 |
| Suministro incluye valores negociables | No |
| Verbal por excepcionalidad | Solo emergencia |
| Libertad pactos y buena fe | Buena administración |
| Concesión sin riesgo | Concesión implica riesgo operacional |

## Repaso de una página

- Ley 9/2017.
- Principios: libertad acceso, publicidad, transparencia, igualdad y no discriminación.
- Criterios sociales y medioambientales siempre vinculados al objeto.
- Libertad de pactos: interés público, ordenamiento jurídico, buena administración.
- Contratación verbal prohibida salvo emergencia.
- Menor: obras < 40.000; suministros/servicios < 15.000.
- Suministro: adquisición o arrendamiento de bienes muebles.
- Excluido: arbitraje y conciliación.
- Concesión: transferencia de riesgo operacional.
- Abierto: cualquiera presenta oferta.
- Restringido: solo seleccionados presentan oferta.
- Negociado: se negocian condiciones.
