# Tema 15. Esquema de documentos, registros y archivos

## Epigrafe oficial

Documentos administrativos: concepto, funciones, clasificación y características. Documento electrónico. Registro de documentos: concepto, funciones, presentación, recepción, entrada y salida. Archivo: concepto, funciones, clases y ordenación. Acceso a documentos: límites y formas.

## Mapa de estudio

| Bloque | Clave |
| --- | --- |
| Documentos | Solicitud, denuncia, alegación, recurso, informe, resolución. |
| Documento electrónico | Firma/sello, metadatos, integridad, conservación. |
| Registro | Entrada/salida, asiento, recibo, remisión. |
| OAMR | Digitalización de papel y asistencia. |
| Archivo | Gestión, central, intermedio, histórico. |
| Acceso | Interesado, transparencia, archivo, límites. |

## 1. Documentos básicos

| Documento | Respuesta |
| --- | --- |
| Solicitud | Inicia procedimiento a instancia de interesado. |
| Denuncia | Comunica hechos para posible inicio de oficio. |
| Alegación | Argumentos durante tramitación. |
| Recurso | Impugna un acto por nulidad/anulabilidad. |
| Oficio | Comunicación formal. |
| Informe | Juicio técnico o jurídico. |
| Resolución | Decide. |
| Notificación | Comunica un acto. |
| Certificado | Acredita datos. |
| Diligencia | Hace constar actuación. |

## 3. Documento electrónico

| Elemento | Clave |
| --- | --- |
| Identificación | Autor u órgano. |
| Contenido | Información del documento. |
| Firma/sello | Si procede. |
| Metadatos | Contexto, gestión, búsqueda, conservación. |
| Integridad | No alteración. |
| Autenticidad | Origen cierto. |
| Conservación | Acceso y legibilidad en el tiempo. |

## 4. Registro

| Concepto | Clave |
| --- | --- |
| Registro | Constancia oficial de entrada y salida. |
| Asiento | Anotación con número, fecha, hora, interesado, órgano y asunto. |
| Entrada | Documentos que llegan a la Administración. |
| Salida | Documentos que emite la Administración. |
| Recibo | Justificante de presentación. |
| OAMR | Digitaliza documentos presenciales. |

## 5. Archivo

| Tipo | Uso |
| --- | --- |
| Oficina o gestión | Expedientes vivos o de uso frecuente. |
| Central | Expedientes finalizados. |
| Intermedio | Documentación semiactiva y valoración. |
| Histórico | Conservación permanente. |

## 6. Ordenación

| Criterio | Ejemplo |
| --- | --- |
| Alfabético | Apellidos. |
| Numérico | Número de expediente. |
| Cronológico | Fecha. |
| Geográfico | Municipio. |
| Orgánico | Órgano productor. |
| Funcional | Función administrativa. |
| Materias | Asunto. |

## 7. Acceso

| Vía | Clave |
| --- | --- |
| Interesado | Acceso al expediente. |
| Transparencia | Información pública con límites. |
| Archivo | Consulta documental. |
| Protección de datos | Datos propios y límites. |

Límites típicos: datos personales, seguridad pública, defensa, relaciones exteriores, confidencialidad, investigaciones, propiedad intelectual, intereses económicos y conservación.

## 8. Trampas

- Digitaliza la OAMR, no el interesado.
- El original se devuelve tras digitalizar, salvo excepción.
- Copia auténtica: 15 días, no 10.
- Denuncia no es recurso.
- Registro no es archivo.
- Clasificar no es ordenar.
- Acceso no es absoluto.
