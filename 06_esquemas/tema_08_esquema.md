# Tema 8. Transparencia y proteccion de datos - Esquema de repaso

## Núcleo oficial

Ley 19/2013: ámbito, publicidad activa y derecho de acceso. Comunidad de Madrid. LO 3/2018: principios, derechos, DPD, responsable, encargado y sector público.

## Ley 19/2013

| Título | Denominación |
| --- | --- |
| I | Transparencia de la actividad pública |
| II | Buen Gobierno |
| III | Consejo de Transparencia y Buen Gobierno |

## Derecho de acceso

| Punto | Regla |
| --- | --- |
| Titulares | Todas las personas |
| Base | Art. 105.b) CE |
| Solicitud | Motivación voluntaria |
| Resolución | 1 mes |
| Ampliación | Otro mes por volumen/complejidad |
| Silencio | Desestimatorio |
| Lengua | Cooficial en el territorio correspondiente |

## Publicidad activa y Portal

| Punto | Clave |

## CTBG

| Punto | Regla |
| --- | --- |
| Órganos | Presidente y Comisión |
| Presidente | Preside también la Comisión |
| Mandato | 5 años no renovable |
| Cese | Expiración, petición propia, separación por Gobierno, incapacidad, incompatibilidad, condena |

## Protección de datos

| Concepto | Clave |
| --- | --- |
| Principios | Licitud, finalidad, minimización, exactitud, conservación, seguridad, responsabilidad |
| Derechos | Acceso, rectificación, supresión, oposición, limitación, portabilidad, no automatizadas |
| Menores | Consentimiento desde mayor de 14 años |
| Responsable | Decide fines y medios |
| Encargado | Trata datos por cuenta del responsable |
| DPD | Informa, asesora, supervisa y coopera |
| Sector público | DPD obligatorio salvo tribunales en función judicial |

## Trampas

| Trampa | Correcto |
| --- | --- |
| Acceso solo españoles | Todas las personas |
| Solicitud siempre motivada | Motivación voluntaria |
| Plazo 15 días o 2 meses | 1 mes ampliable otro |

| Título III = Buen Gobierno | No: CTBG |

| CTBG con AEPD como órgano | Órganos: Presidente y Comisión |

| Seguridad pública en DPD | No: seguridad privada |

## Repaso de una pagina

- Ley 19/2013: transparencia, acceso, buen gobierno.
- Acceso: todas las personas.
- Solicitud: identificar, información solicitada, contacto; motivación voluntaria.
- Resolución: 1 mes, ampliable otro; silencio desestimatorio.
- Límites: seguridad nacional, seguridad pública, ilícitos, datos, intereses económicos, medio ambiente.
- Portal: accesibilidad, interoperabilidad y reutilización.
- CTBG: Presidente y Comisión.
- CAM: Plan de Gobierno = compromisos; DG Atención al Ciudadano y Transparencia.
- RGPD: principios y derechos.
- Responsable decide; encargado trata por cuenta.
- DPD obligatorio en sector público.
- Menores: consentimiento desde mayor de 14 años.
