# CAM C2 Write Temario

## Workflow

1. Identify the official topic number and file target in `05_temario/`.
2. Read `references/tema-template.md` and follow its section order.
3. Consult `04_estadisticas/` and `02_preguntas_extraidas/preguntas_normalizadas.json` when available to prioritize historically asked material.
4. For legislation, verify the current legal text from official sources before asserting live rules, especially if the user asks for a complete or current version.
5. Write concise, exam-oriented explanations. Do not create encyclopedic commentary.
6. Create or update the matching quick-review file in `06_esquemas/` when requested.

## Writing Rules

- Explain in plain Spanish.
- Prefer tables, lists, and contrastive summaries over long prose.
- Quote legislation only for indispensable fragments; otherwise paraphrase and cite article numbers.
- Include only articles likely to be examined or needed to resolve test questions.
- Include typical traps and confusions.
- Keep historical questions traceable by id and source when available.

## Priority Order

Follow the project order unless the user chooses another topic: Word, Excel, Windows, Outlook, Microsoft 365, psychotechnical material, Constitución, Estatuto de Autonomía, Ley 39/2015, Transparencia, Función Pública, then the remaining materias.
