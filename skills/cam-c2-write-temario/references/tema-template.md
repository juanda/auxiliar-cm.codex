# Tema Template

Use this section order for each file under `05_temario/`:

1. `# Tema NN. Título oficial`
2. `## 1. Resumen ejecutivo`
3. `## 2. Desarrollo`
4. `## 3. Conceptos clave`
5. `## 4. Artículos importantes`
6. `## 5. Errores tipicos`
7. `## 6. Preguntas históricas`
8. `## 7. Test de entrenamiento`
9. `## 8. Esquema final`

Guidelines:

- The executive summary must fit approximately two printed pages.
- The training test should include 20-50 new questions unless the user asks for another size.
- Use tables for concepts, articles, and common confusions.
- Keep article references concise: law, article, and exam relevance.
