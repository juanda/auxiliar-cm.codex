# Tema 21. Trabajo colaborativo: Microsoft 365

Trabajo colaborativo: herramientas y funcionalidades. Microsoft 365: Teams, SharePoint, OneDrive y Outlook. Videoconferencias.

## 1. Resumen ejecutivo

La version oficial para el Bloque II en la convocatoria 2026 es `Windows 10` y `Microsoft 365 version escritorio`. Para este tema, esto significa estudiar las herramientas de colaboracion de Microsoft 365 desde un punto de vista practico: que hace cada aplicacion, como se comparten documentos, como se sincronizan archivos, como se organizan equipos y reuniones, y que diferencias hay entre Teams, SharePoint, OneDrive y Outlook.

El Tema 21 tiene 12 preguntas historicas clasificadas:

| Subtema | Preguntas historicas |
| --- | ---: |
| Navegacion web y protocolos | 7 |
| Teams y videoconferencias | 3 |
| SharePoint | 2 |

Hay una incidencia importante: varias preguntas de 2023 clasificadas como Tema 21 tratan conceptos generales de Internet, navegadores y protocolos. Aunque el epigrafe oficial 2026 se centra expresamente en colaboracion y Microsoft 365, conviene mantener esos contenidos porque ya han aparecido en el segundo ejercicio de ofimatica.

Los puntos de mayor rendimiento son:

- SharePoint como plataforma para organizar, compartir y colaborar con informacion y documentos de forma segura.
- OneDrive como herramienta de almacenamiento personal y sincronizacion.
- Sincronizacion de archivos de SharePoint mediante OneDrive para trabajar desde el equipo local.
- Teams como espacio de colaboracion formado por personas, contenido y herramientas.
- Diferencia entre equipo, canal, chat y reunion.
- Reuniones de Teams: audio, video, pantalla, programacion, `Reunirse ahora`, grabacion y participantes externos.
- Roles en reuniones de Teams: organizador, coorganizador, presentador y asistente.
- Outlook como apoyo a la colaboracion mediante correo, calendario, convocatorias y reuniones.
- Marcadores del navegador, modo incognito, HTTPS, FTP/SFTP y navegadores web.

Idea clave: Microsoft 365 no es solo una suma de aplicaciones. En colaboracion, Teams organiza la conversacion y las reuniones; SharePoint guarda y estructura documentos de equipo; OneDrive sincroniza y permite acceso local; Outlook gestiona correo, agenda e invitaciones.

## 2. Desarrollo

### 2.1. Trabajo colaborativo en Microsoft 365

El trabajo colaborativo es la actividad realizada por varias personas sobre informacion, documentos, conversaciones, tareas o reuniones compartidas. En Microsoft 365 se apoya en aplicaciones conectadas entre si.

| Herramienta | Funcion principal en colaboracion |
| --- | --- |
| Teams | Conversaciones, equipos, canales, reuniones y videoconferencias. |
| SharePoint | Sitios, bibliotecas documentales, paginas, listas y permisos de equipo. |
| OneDrive | Almacenamiento personal, sincronizacion y comparticion de archivos. |
| Outlook | Correo, calendario, convocatorias y seguimiento de comunicaciones. |

No debe memorizarse como compartimentos aislados. En la practica:

- Los archivos de un equipo de Teams se almacenan en SharePoint.
- Los archivos personales compartidos suelen estar en OneDrive.
- Las reuniones de Teams pueden programarse desde Teams u Outlook.
- Las convocatorias, respuestas y calendarios se gestionan con Outlook/Exchange.

### 2.2. Teams

Microsoft Teams es una herramienta de colaboracion de Microsoft 365. Permite reunir personas, conversaciones, archivos, aplicaciones y reuniones en espacios de trabajo.

Pregunta historica: `2025-E2-027`.

#### Equipo

Un `equipo` en Teams es un conjunto de personas, contenido y herramientas organizadas para colaborar de forma conjunta.

| Elemento | Explicacion |
| --- | --- |
| Equipo | Grupo de colaboracion estable. |
| Propietario | Usuario con capacidad de administracion del equipo. |
| Miembro | Usuario que participa en el equipo. |
| Invitado | Usuario externo admitido segun configuracion de la organizacion. |

Trampa de examen: un equipo no es solo una carpeta compartida ni un chat temporal. Integra personas, conversaciones, archivos y herramientas.

#### Canales

Los canales organizan el trabajo dentro de un equipo por materias, proyectos o unidades.

| Tipo de canal | Uso orientativo |
| --- | --- |
| General | Canal inicial de un equipo. |
| Estandar | Visible para los miembros del equipo. |
| Privado | Accesible solo para un subconjunto de miembros. |
| Compartido | Puede colaborar con personas de otros equipos u organizaciones, si esta permitido. |

En los canales se pueden publicar mensajes, mantener conversaciones, compartir archivos y anadir pestanas con aplicaciones o documentos.

#### Chat

El chat sirve para comunicaciones directas entre usuarios o grupos reducidos. A diferencia del canal, el chat no organiza por si mismo el trabajo de todo un equipo.

| Chat | Canal |
| --- | --- |
| Conversacion directa o de grupo. | Espacio de trabajo dentro de un equipo. |
| Mas informal o puntual. | Mas estructurado y persistente. |
| No sustituye necesariamente a un equipo. | Agrupa personas, archivos y herramientas del equipo. |

### 2.3. Reuniones y videoconferencias en Teams

Teams permite celebrar reuniones con audio, video, chat y uso compartido de pantalla. Pueden programarse para una fecha concreta o iniciarse de forma inmediata con `Reunirse ahora`.

Pregunta historica: `2025-E2-029`.

| Funcion | Utilidad |
| --- | --- |
| Audio | Comunicacion por voz. |
| Video | Imagen de participantes. |
| Compartir pantalla | Mostrar escritorio, ventana o contenido. |
| Chat de reunion | Mensajes escritos durante la reunion. |
| Grabacion | Conserva audio y video para consulta posterior, si la organizacion lo permite. |
| Subtitulos/transcripcion | Facilitan seguimiento y accesibilidad, segun configuracion. |
| Sala de espera | Controla la entrada de asistentes. |

La afirmacion "las reuniones de Teams solo pueden celebrarse si todos los participantes pertenecen a la misma organizacion" es falsa. Pueden participar invitados o externos si la configuracion de la organizacion lo permite.

#### Programar e iniciar reuniones

| Opcion | Significado |
| --- | --- |
| Reunión programada | Se crea con fecha, hora, asistentes y convocatoria. |
| Reunirse ahora | Inicia una reunion inmediata. |
| Reunion de canal | Asociada a un canal concreto. |
| Convocatoria desde Outlook | Invitacion de calendario con enlace de Teams. |

#### Roles en reuniones de Teams

Los roles definen que puede hacer cada persona en la reunion.

Pregunta historica: `2025-E2-030`.

| Rol | Idea de examen |
| --- | --- |
| Organizador | Mayor control: configura la reunion y gestiona participantes. |
| Coorganizador | Ayuda a gestionar la reunion con permisos amplios. |
| Presentador | Puede compartir contenido y realizar acciones de presentacion. |
| Asistente | Participa con permisos mas limitados. |

Trampa: el rol con mayor nivel de control es el `organizador`, no el presentador ni el invitado.

### 2.4. SharePoint

SharePoint es la plataforma de Microsoft que permite crear sitios y organizar, compartir y colaborar con informacion y documentos dentro de una organizacion. Microsoft lo presenta como un lugar seguro para almacenar, organizar, compartir y acceder a informacion desde distintos dispositivos mediante navegador.

Pregunta historica: `2025-E2-026`.

| Elemento | Funcion |
| --- | --- |
| Sitio | Espacio de trabajo o publicacion. |
| Sitio de equipo | Colaboracion interna de un grupo o proyecto. |
| Sitio de comunicacion | Difusion de informacion a una audiencia amplia. |
| Biblioteca de documentos | Almacena archivos y permite gestionarlos. |
| Lista | Datos estructurados en filas y columnas. |
| Pagina | Contenido informativo dentro del sitio. |
| Permisos | Controlan quien puede ver, editar o administrar. |

SharePoint no debe confundirse con PowerPoint, Publisher o Visual Studio. Su nucleo examinable es la colaboracion documental y la gestion de informacion.

#### Bibliotecas de documentos

Una biblioteca de documentos es un contenedor de archivos en SharePoint.

Funciones habituales:

- Subir documentos.
- Crear carpetas.
- Compartir archivos.
- Controlar permisos.
- Ver historial de versiones.
- Abrir documentos en aplicacion de escritorio o navegador.
- Sincronizar con el equipo mediante OneDrive.

#### Versiones y coautoria

Microsoft 365 permite que varias personas trabajen sobre documentos compartidos. En Word, Excel o PowerPoint se puede editar un archivo compartido y conservar cambios en la nube.

| Concepto | Significado |
| --- | --- |
| Coautoria | Varias personas editan el mismo documento. |
| Historial de versiones | Permite consultar o recuperar versiones anteriores. |
| Comentarios | Anotaciones vinculadas al documento. |
| Menciones | Avisos a usuarios mediante `@`. |
| Permisos | Determinan lectura, edicion o administracion. |

Trampa: enviar copias por correo genera duplicados; compartir un vinculo a un archivo centralizado facilita trabajar sobre una version comun.

### 2.5. OneDrive

OneDrive es el servicio de almacenamiento en la nube de Microsoft. En un entorno de trabajo o educativo, OneDrive permite guardar archivos personales de trabajo, compartirlos y sincronizarlos con el equipo.

| Funcion | Explicacion |
| --- | --- |
| Almacenamiento personal | Archivos del usuario. |
| Compartir | Enviar vinculo con permisos. |
| Sincronizacion | Mantener copia local y copia en la nube coordinadas. |
| Archivos a peticion | Ver archivos en el Explorador sin descargarlos todos inicialmente, segun configuracion. |
| Recuperacion/versiones | Posible recuperacion de cambios o versiones, si esta disponible. |

#### Sincronizacion de SharePoint mediante OneDrive

Pregunta historica: `2025-E2-028`.

La sincronizacion de archivos de SharePoint o Teams mediante OneDrive permite acceder y trabajar con archivos desde el equipo local, sincronizando automaticamente los cambios con SharePoint cuando hay conexion.

| Opcion | Resultado |
| --- | --- |
| Trabajar en navegador | Acceso web a SharePoint/Teams. |
| Sincronizar con OneDrive | Los archivos aparecen en el Explorador de archivos. |
| Acceso sin conexion | Puede trabajarse localmente sobre archivos sincronizados. |
| Volver a estar conectado | Se sincronizan los cambios. |

Trampas:

- OneDrive si permite sincronizar archivos.
- Sincronizar no significa trabajar solo desde el navegador.
- Si no hay permisos de edicion, los cambios pueden no sincronizarse.

### 2.6. Outlook dentro del trabajo colaborativo

Outlook ya se estudia en el Tema 20 como correo y agenda, pero en el Tema 21 interesa su integracion con Microsoft 365:

| Funcion | Relacion con colaboracion |
| --- | --- |
| Correo | Comunicacion formal entre usuarios. |
| Calendario | Planificacion de reuniones y disponibilidad. |
| Convocatorias | Invitaciones a reuniones, incluidas reuniones de Teams. |
| Contactos | Seleccion de destinatarios y asistentes. |
| Adjuntos/vinculos | Envio de archivos o enlaces a OneDrive/SharePoint. |

En entornos Microsoft 365, Outlook puede incluir un enlace de reunion de Teams en una convocatoria y permite responder aceptando, rechazando o proponiendo otra hora.

### 2.7. Compartir archivos y permisos

Compartir en Microsoft 365 suele hacerse mediante vinculos con permisos.

| Permiso | Significado |
| --- | --- |
| Puede ver | Acceso de lectura. |
| Puede editar | Permite modificar el archivo. |
| Personas especificas | Solo usuarios indicados. |
| Personas de la organizacion | Usuarios internos con el enlace. |
| Cualquiera con el vinculo | Acceso mas amplio, si la organizacion lo permite. |

Buenas practicas administrativas:

- Dar solo el permiso necesario.
- Usar `Personas especificas` cuando el documento sea sensible.
- Evitar adjuntar multiples copias si conviene trabajar sobre un documento unico.
- Revisar que se comparte el archivo correcto y no una carpeta completa innecesaria.

### 2.8. Navegadores, marcadores y modo incognito

Aunque no forman parte estricta del epigrafe "Microsoft 365", aparecieron historicamente en el Tema 21 y deben repasarse.

#### Marcadores

Pregunta historica: `2023-E2-008`.

Los marcadores o favoritos son la utilidad del navegador que permite guardar direcciones de paginas web de interes para acceder a ellas rapidamente.

| Concepto | No confundir con |
| --- | --- |
| Marcador/favorito | Historial de navegacion. |
| Historial | Registro de paginas visitadas. |
| Hipervinculo/link | Enlace dentro de una pagina o documento. |
| Descargas | Gestion de archivos descargados. |

#### Modo incognito o privado

Pregunta historica: `2023-E2-022`.

La navegacion en modo incognito es una funcion de privacidad disponible en algunos navegadores. Normalmente evita guardar en el dispositivo ciertos datos locales de la sesion, como historial local, cookies al cerrar o datos de formularios, segun navegador.

No significa:

- Navegacion anonima absoluta.
- Proteccion total frente a la organizacion, proveedor de Internet o sitios web.
- Antivirus.
- Modo oscuro.

#### Navegadores web

Pregunta historica: `2023-E2-030`.

| Son navegadores | No es navegador en la pregunta historica |
| --- | --- |
| Microsoft Edge, Chrome, Firefox, Opera, Brave | Rust |

Rust es un lenguaje de programacion, no un navegador web.

### 2.9. Internet, ARPANET y protocolos

#### ARPANET

Pregunta historica: `2023-E2-009`.

ARPANET fue una red de origen militar y academico, antecedente historico de Internet. En examen se identifica como uno de los origenes del actual Internet, no como sistema operativo, red Wi-Fi personal ni firewall.

#### HTTP y HTTPS

Pregunta historica: `2023-E2-032`.

| Protocolo | Idea clave |
| --- | --- |
| HTTP | Protocolo de transferencia de hipertexto. |
| HTTPS | Version segura de HTTP mediante cifrado. |

HTTPS cifra las comunicaciones y utiliza certificados de clave publica en el servidor. Es falso que solo sea reconocido por Firefox o Chrome: lo reconocen los navegadores modernos.

#### FTP y SFTP

Pregunta historica: `2023-E2-014`.

| Protocolo | Funcion |
| --- | --- |
| FTP | Transferencia de archivos sin canal seguro por defecto. |
| SFTP | Transferencia de archivos mediante canal seguro. |

La diferencia principal es la seguridad del canal. No son iguales.

### 2.10. Integracion entre herramientas

| Situacion | Herramienta mas propia |
| --- | --- |
| Conversar en un proyecto estable | Teams, canal del equipo. |
| Reunirse por videoconferencia | Teams. |
| Guardar documentos de una unidad o proyecto | SharePoint. |
| Guardar archivos personales de trabajo | OneDrive. |
| Sincronizar biblioteca en el Explorador | OneDrive. |
| Enviar convocatoria formal | Outlook. |
| Compartir documento para coedicion | OneDrive o SharePoint. |
| Publicar informacion interna | SharePoint. |

Idea de examen: si el enunciado habla de "organizar, compartir y colaborar con informacion y documentos de forma segura dentro de una organizacion", la respuesta esperada es SharePoint. Si habla de "equipo" como personas, contenido y herramientas, la respuesta es Teams. Si habla de sincronizar archivos con el equipo local, entra OneDrive.

## 5. Errores tipicos

| Error o trampa | Correccion |
| --- | --- |
| Confundir Teams con una carpeta | Teams integra personas, conversaciones, archivos, herramientas y reuniones. |
| Decir que un equipo es un chat temporal | Un equipo es un espacio colaborativo estable. |
| Confundir canal y chat | Canal pertenece a un equipo; chat es conversacion directa o de grupo. |
| Pensar que SharePoint es PowerPoint | SharePoint organiza y comparte informacion y documentos. |
| Decir que OneDrive no sincroniza archivos | OneDrive permite sincronizar archivos y bibliotecas. |
| Creer que sincronizar obliga a trabajar solo en navegador | La sincronizacion permite trabajar desde el equipo local. |
| Pensar que Teams solo permite reuniones internas | Puede admitir externos si la organizacion lo permite. |
| Confundir organizador y presentador | El organizador tiene mayor control sobre la reunion. |
| Creer que el modo incognito hace anonimo al usuario | Solo limita ciertos rastros locales; no da anonimato total. |
| Confundir marcadores con historial | Marcadores guardan direcciones; historial registra paginas visitadas. |
| Decir que HTTPS solo funciona en Chrome o Firefox | HTTPS es reconocido por navegadores modernos. |
| Confundir FTP y SFTP | SFTP usa canal seguro; FTP no por defecto. |
| Considerar Rust un navegador | Rust es un lenguaje de programacion. |

## 8. Esquema final

### Mapa de herramientas

| Necesidad | Herramienta |
| --- | --- |
| Conversaciones de equipo | Teams |
| Videoconferencia | Teams |
| Documentos de grupo | SharePoint |
| Archivos personales y sincronizacion | OneDrive |
| Correo, agenda y convocatorias | Outlook |

### Teams

- Equipo = personas + contenido + herramientas.
- Canal = organizacion del trabajo dentro del equipo.
- Chat = conversacion directa o de grupo.
- Reunion = audio, video, chat, pantalla y posible grabacion.
- `Reunirse ahora` = reunion inmediata.
- Rol con mas control = organizador.

### SharePoint y OneDrive

- SharePoint = organizar, compartir y colaborar con informacion y documentos.
- Biblioteca = repositorio de documentos.
- OneDrive = almacenamiento personal y sincronizacion.
- Sincronizar SharePoint con OneDrive = trabajar desde Explorador y sincronizar cambios.
- Coautoria = varias personas sobre un documento.
- Historial de versiones = recuperar estados anteriores.

### Outlook

- Correo y calendario.
- Convocatorias de reunion.
- Puede integrar enlace de Teams.
- Adjuntos o vinculos a OneDrive/SharePoint.

### Navegacion y protocolos

- Marcador = direccion web guardada.
- Historial = paginas visitadas.
- Modo incognito = privacidad local, no anonimato total.
- HTTPS = HTTP seguro con cifrado.
- FTP = transferencia de archivos.
- SFTP = transferencia por canal seguro.
- ARPANET = antecedente de Internet.
- Rust no es navegador.

### Trampas de examen

- SharePoint no es PowerPoint.
- OneDrive si sincroniza archivos.
- Teams no es solo una carpeta.
- Un equipo no es un chat temporal.
- Organizador tiene mas control que presentador.
- Las reuniones de Teams no se limitan necesariamente a usuarios de la misma organizacion.
- `CCO` y Outlook pertenecen al Tema 20, pero Outlook integra convocatorias y colaboracion.
